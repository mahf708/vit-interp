# Hackathon playground: inside a ViT weather emulator

Eight notebooks that go from "run the model" to circuits and physics laws, with one helper
module, `vit_interp.playground` (`pg`), that keeps every cell to a line or three. Nothing has
to be coded from scratch. Each notebook ends with a **Try this** list to branch off from.

| Notebook | What you do | Main helpers |
|---|---|---|
| `00_quickstart` | run one 6-h step and a 5-day forecast against E3SM; see where errors grow; read the year-long evaluation | `pg.load`, `pg.state`, `pg.step`, `pg.rollout`, `pg.plot_maps` |
| `01_attention_atlas` | a table of all 48 heads: how far and in which direction they look (upstream? local? global?); attention maps from chosen points | `pg.head_atlas`, `pg.attention`, `pg.plot_tokens` |
| `02_logit_lens` | decode the residual stream after every block: when does the model "know" the answer for winds vs moisture? | `pg.lens` |
| `03_ablation_lab` | knock out heads/MLPs (mean or zero), see which fields and regions break; sweep all 56 components for a metric | `pg.ablate`, `pg.sweep_components`, `pg.box`, `pg.box_mean` |
| `04_direct_attribution` | which head or MLP *writes* the V_3 tendency over a box, as maps that add up exactly to the output; direct vs total effect | `pg.direct_attribution` |
| `05_exege_latents` | export a latent archive and use [exege](https://github.com/mahf708/exege): channels that respond in a region, similarity maps, PCA, a sparse autoencoder | `python -m vit_interp.export`, `exege latents …`, `exege nn sae` |
| `06_rossby_probe` | LAWFUL-style: plant a Rossby wave and test the model's phase speeds against c − U = −β/K²; which layers carry it | `vit_interp.rossby` |
| `07_exege_circuits_and_laws` | the papers' methods through exege on the real model: Vi-CD edge circuits (EAP, pruning, faithfulness curve, stable cores) and LAWFUL (Rossby consistency, sufficiency/necessity, τ-circuit search) | `exege.circuits`, `exege.laws` |

## The model in one paragraph

Input: 34 prognostic fields (PS, TS, and T, U, V, total water on 8 levels; level 0 is the
top, 7 near the surface) and 5 forcings, on the 1° E3SMv3 AMIP grid. Patches are 4°×4°,
so there are 45×90 = 4050 tokens, each with a learned position embedding (the only source
of latitude). The body is 8 pre-LN blocks with 6 heads × 64 dims and an MLP ×4. Output: the
6-h tendency. Trained on 2000–2009; the notebooks use 2010. Hook names follow
TransformerLens (`blocks.{i}.attn.hook_pattern`, `hook_result` per head,
`blocks.{i}.hook_resid_post`, …; see `vit_interp/model.py`).

## Cheat sheet

```python
from vit_interp import playground as pg
em, meta = pg.load()
x = pg.state("2010-07-20T12")                       # (1, 39, 180, 360) physical
nxt, tend = pg.step(em, x)                          # tendency: (1, 34, 180, 360) per 6 h
pg.plot_map(tend[0, pg.ch("T_7")], "T_7 tendency")
mask = pg.box(35, 60, 280, 320)                     # lat0, lat1, lon0, lon1
pg.box_mean(tend[0, pg.ch("V_3")], mask)
pg.attention(em, x, layer=5, head=4, query=(50, 330))     # (45, 90)
pg.ablate(em, x, names=["L5H2", "L6MLP"], mode="mean").rel_change()
maps, table = pg.direct_attribution(em, x, "V_3", mask)
decoded, table = pg.lens(em, x)
nxt, tend = pg.step(em, x, hooks={"blocks.3.attn.hook_z": lambda z: 0 * z})  # any hook
```

## Open questions to explore

Circuits (*Seeing Through Circuits*, Vi-CD):

1. Is there an **advection circuit**? Look for heads that read upstream (dx < 0 in the
   midlatitudes, notebook 01), then check that ablating them breaks the tendency downstream
   of strong gradients (03) and that they write it directly (04).
2. Edge-level circuits for a regional metric (`vit_interp.circuits` here, `exege.circuits`
   for the general tool). How sparse is the circuit for "V_3 tendency in the North
   Atlantic"? Is it the same circuit in the North Pacific, and in July?
3. Vi-CD finds that related classes share circuits. Do related **regimes** share them:
   blocking vs zonal flow, El Niño vs La Niña tropics?
4. What makes a good "corrupted" input for an emulator: another day, the climatology, or
   the same day with one feature (a cyclone, a front) removed? Does the circuit depend on
   the choice?

Physics (*LAWFUL*; *A Mechanistic Analysis of Transformers for Dynamical Systems*):

5. Notebook 06 measures Rossby dispersion: long waves do retrogress relative to the flow,
   with the right sign. Is the magnitude right? Which latitude and wavenumber range is the
   model's "domain of validity"?
6. β depends on latitude, and the model only knows latitude through `pos_embed`. Can you
   find β in it, for example by probing the position embedding for cos(lat)? What happens
   to the Rossby response if you swap two latitude rows of `pos_embed`?
7. Does any head act like a **finite-difference stencil** (fixed offset, symmetric
   east/west weights)? Or like a **semi-Lagrangian** step, attention following the wind?
   Correlate a head's dx with the local U (notebook 01, question 5).
8. Conservation: does any component write a near-uniform PS tendency, a global mass
   correction? (Layer-0 heads are near-uniform averagers.)
9. Linearity and superposition: plant two waves at once. Is the response the sum of the
   two single responses?

Errors (*Rethinking Circuit Evaluation: Do Circuits Explain Model Errors?*):

10. The free run drifts (see the evaluation summary). Find the components whose ablation
    *reduces* the 5-day error. Is the error carried by a circuit, and is it the same circuit
    as the skill?
11. Where are patch-edge artifacts born? Use the lens (02) and direct attribution (04) on
    the 4°-periodic part of the tendency.
12. Do 5-day errors grow first where the attention atlas says information comes from far
    away (global heads), or where it is local?

Representations (exege, notebook 05):

13. Train an SAE on the last block. Find features for fronts, the ITCZ, sea-ice edges, the
    diurnal cycle (SOLIN), or orography (PHIS). Steer along one and see what the next step
    does.
14. Is the residual stream organized by **place** (position embedding dominant) or by
    **weather**? Compare region similarity maps at layer 1 and layer 7.
15. What does the model do with the 5 forcing fields? Ablate the SOLIN direction in the
    embedding and look at the diurnal cycle of TS.
